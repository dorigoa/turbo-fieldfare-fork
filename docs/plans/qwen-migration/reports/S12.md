## Valori misurati o fissati

- `Tolerance.fp16Reduction` = 5e-3 (C8) usata come soglia; errori misurati su
  tutti i 15 casi dei test (relErr massimo, maxAbs massimo per kernel):
  - RMSNorm di riga: relErr ≤ 4.3e-04, maxAbs ≤ 1.9e-03 (`1+w`, d = 2048).
  - RMSNorm per testa: relErr ≤ 4.4e-04 (caso peggiore: 256×16, `1+w`),
    maxAbs ≤ 1.9e-03.
  - RMSNorm gated: relErr ≤ 2.9e-04, maxAbs ≤ 1.9e-03 (h = 128, 32 teste).
  - L2 per testa: relErr ≤ 3.7e-04, maxAbs ≤ 6.1e-05.
- FC fissato: **200** = `qwen_rms_one_plus_w` (bool). FC 201–204 liberi (C3).
- eps dei test = 1e-6 (valore reale per q/k L2 e RMSNorm, da S8).

## Note per le sezioni successive

- Design S12 (scelto seguendo la scheda): pesi norma **BF16** nel `.gturbo`
  (confermato dal report S6: "BF16 integri (norme, A_log, conv1d)"), input/output
  FP16, accumulo FP32. `linear_attn.norm.weight` usa sempre `w` (3.3 punto 1).
- Function constant: solo FC **200** (`qwen_rms_one_plus_w`, bool; true =
  `x̂·(1+w)`, false/undefined = `x̂·w`). FC 201–204 restano liberi (C3).
  Specializzazione D via FC non necessaria (correttezza prima: D a runtime,
  stile `rmsnorm_bf16w` senza FC).
- Kernel in `qwen_norms.metal`: `qwen_rmsnorm_row` (riga, T righe, grid.x=row),
  `qwen_rmsnorm_perhead` (q/k 256, grid=(head,row), peso BF16 condiviso),
  `qwen_gated_rmsnorm_perhead` (o 128, `rmsnorm·silu(z)`, sempre `w`),
  `qwen_l2norm_perhead` (y = x·rsqrt(Σx²+eps), **somma** non media; la scala
  `1/sqrt(128)` del q in 3.5 NON è nel kernel: la applichi chi chiama/S15).
- Wrapper Swift: `Sources/TurboFieldfare/Kernels/Qwen/QwenNorms.swift`,
  classe `QwenNorms`, due PSO per i kernel con peso (plain e 1+w via FC 200).
- Riferimento CPU: `QwenNormRef` in
  `Sources/TurboFieldfareValidation/Support/Reference/Qwen/QwenNormRefs.swift`
  (vDSP per la somma dei quadrati, catene di arrotondamento diverse dal kernel).
- Test: `Tests/TurboFieldfare/Core/Kernels/Qwen/QwenNormsTests.swift`,
  helper esistenti: `SeedTree`/`SplitMix64.uniform`, `Fp16Buffer`,
  `RelError.compute/maxAbsDiff`, `Quantization.bf16Bits/bf16ToFloat`,
  `Tolerance.fp16Reduction` (5e-3). Il target è
  `TurboFieldfareValidationSupport` (path `Sources/TurboFieldfareValidation/Support`,
  sottocartelle incluse senza modifiche a Package.swift; `.copy("Metal")`
  copre anche `Metal/Qwen/`).
- I 5 file Metal placeholder sono tutti in coda a `shaderModules` (l'unica
  translation unit combinata non deve avere collisioni: prefisso `qwen_`).
- Nota S8: `nn.RMSNorm` MLX = `x̂·w` con pesi già spostati ✓; eps q/k L2 = 1e-6
