## Note per le sezioni successive
- Il parser di S11 (`QwenAssistantDecoder`, `allowedTools: []`) scatta solo nella modalità chat, dove il prompt di generazione porta il frame think; `--prompt` grezzo va su stdout come nel golden S8; `--no-thinking` in modalità grezza non ha effetto (non c'è template).
- Nel CLI le tool call non hanno superficie: un blocco tool emesso dal modello avvelena il decoder (`unknownTool`), la generazione si ferma e l'exit code è 1.
- Il footer della riga variante ora contiene `family=` anche per Gemma (`family=gemma4`): cambio di output richiesto dalla scheda S22, non un regression di Gemma.
