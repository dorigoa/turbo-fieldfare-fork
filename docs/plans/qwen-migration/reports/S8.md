## Note per le sezioni successive
- Classi MLX installate (`mlx_lm/models/`): modello registry `qwen3_5_moe.py` → `Model` (rimappa prefix, divide `experts.gate_up_proj` in `switch_mlp.{gate,up}_proj`) sopra `qwen3_5.py`: `TextModelArgs`, `GatedDeltaNet`, `DecoderLayer` (`is_linear = (idx+1) % 4 != 0`), `Qwen3_5TextModel` (loop + `norm`), `TextModel` (`lm_head` non legato; `sanitize` aggiunge +1 alle norme SOLO se `conv1d` è in layout HF → qui no: i pesi sono già spostati), `Model` (wrapper `language_model`); attention/MoE/norm-gated riusati da `qwen3_next.py` (`Qwen3NextAttention`, `Qwen3NextSparseMoeBlock`, `Qwen3NextRMSNormGated`); ricorrenza in `gated_delta.py` (`normalize_qk`, `compute_g`, `gated_delta_update`→`gated_delta_ops`/kernel)
- **`nn.RMSNorm` MLX = `x̂·w`** (verificato numericamente, niente `1+w`): con pesi già spostati coincide con 3.5 con `normWeightsShifted=true` ✓
- `normalize_qk(q,k,inv_scale=128^-0.5,eps=1e-6)`: `q ← 128⁻¹·x̂` con `x̂=x·rsqrt(mean(x²)+1e-6/128)`, `k ← 128^-0.5·x̂` — algebricamente identico a 3.5 (`rsqrt(Σq²+1e-6)` e `/sqrt(128)`) ✓
- `compute_g`: `g = exp(-exp(A_log_f32)·softplus(a+dt_bias))` è il **decay** già esponenziato (3.5: `exp(g_j)`) ✓; `beta = sigmoid(b)`
- Stato DeltaNet in mlx-lm: shape `[B, Hv, Dv, Dk]` FP32 (**riga = dimensione valore, colonna = dimensione chiave**: trasposto rispetto alla notazione di 3.5, matematica identica); golden `state_heads0to3` salvato come `[testa][riga i=chiave][colonna c=valore]`, cioè la trasposizione dello stato MLX
- Mappa teste: `mx.repeat(q/k, Hv//Hk=2, -2)` → la testa di valore `j` usa la testa di chiave `j/2` ✓ (confermato dal codice)
- Conv: `nn.Conv1d(groups=8192, kernel=4)` applicata a `concat([stato(3), qkv])` senza padding → cross-correlazione: `y_c[t] = Σ_j w[c,j,0]·u[t-3+j]`; peso `[8192,4,1]` = (canale, tap, 1)
- RMSNormGated: `precise_swiglu(o, z, rmsnorm_f32(o)·w)` = `silu(z_f32)·rmsnorm_f32` → cast al dtype di input
- Attention: split per-head `[16,512]→(q 256 | gate 256)`; `q_norm`/`k_norm` = `nn.RMSNorm(256, eps=1e-6)` con pesi del checkpoint (già spostati → `x̂·w`); RoPE `initialize_rope(64, base=1e7, traditional=False, scaling=rope_parameters)` = NeoX/rotate_half sulle prime 64; head sharing KV `h/8` via repeat interno a `scaled_dot_product_attention`; `output * sigmoid(gate)` → `o_proj`
- MoE: softmax **precise** su `gate(x)` (8 bit); `argpartition(...,kth=-8)[...,-8:]` (ordine NON garantito per probabilità — nel golden gli ID vanno confrontati come insieme o ordinati); rinormalizzazione top-k **attiva** (`norm_topk_prob=True` di default e nel config) ✓; expert via `SwitchGLU` (SwiGLU = `silu(gate)·up`); `shared = sigmoid(W_sg·x)·shared_mlp(x)`
- Prefill senza cache: `create_ssm_mask → None`, `create_attention_mask → "causal"`; `model(mx.array([ids]))` dà logits `[1,T,V]`
