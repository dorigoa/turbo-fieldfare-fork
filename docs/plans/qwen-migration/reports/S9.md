## Note per le sezioni successive
- I nomi dei marker speciali nei sorgenti Swift sono scritti con escape `"\u{3C}|…|>"`: non incollare mai la forma grezza nei tool input (marcatori di formato chat).
- `QwenTokenizer.decode` è un push-loop su `QwenDetokenizer`: il decode streaming del generatore deve usare `QwenDetokenizer` direttamente (stesso `tokenizer`, `barrierTokenIDs` = `structuralMarkerIDs`), non la libreria (`clean_up_tokenization_spaces` riscriverebbe l'output).
- `encode(_:addBOS:)` ignora `addBOS` (nessun BOS in Qwen); usa `addSpecialTokens:false` come `GFTokenizer`.
- `LanguageModelConfigurationFromHub(modelFolder:)` in questa versione di swift-transformers prende `URL`, non `String`.
