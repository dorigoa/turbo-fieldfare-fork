## Deviazioni dal piano

- Softplus nel kernel: `x > 20 ? x : log(1 + exp(x))` — MSL a questo level non ha `log1p`;
  il riferimento CPU usa `log1p`. Clamp a 20 sia nel kernel che nel ref, quindi identici.
- Nessun function constant: la fascia C3 di S14 (210-219) resta inutilizzata (ammesso dalla scheda).
- `encodeL2PerHead` di S12 indicizza `x` come `[rows][numHeads·headDim]` compatto, ma le fette
  q/k del conv output hanno riga da 8192 elementi: nel test si usa una dispatch per riga
  (rows=1, `xOffset = r·16384` B). Vedi Note.

## Valori misurati o fissati

- Errori relativi massimi (CPU ref, tolleranza C8 `fp16Reduction = 5e-3`):
  conv y: 2.3e-4 … 4.2e-4 (maxAbs ≤ 2.0e-3, stato FP32 `maxAbsDiff == 0` sempre);
  gates: beta ≤ 1.2e-7, decay ≤ 1.8e-7;
  prep: q (L2+scale) ≤ 6.8e-4, k (L2) ≤ 3.8e-4.
- Layout fissati: `conv1d.weight` BF16 `[8192][4][1]` (tap lungo dim 1, cross-correlazione,
  `y_c[t] = Σ_j w[c][j]·u_c[t-3+j]`); stato conv FP32 `[3][8192]` (D5, pre-attivazione);
  split q=[0,2048), k=[2048,4096), v=[4096,8192); scale q = 1/sqrt(128) applicato dopo L2
  (`qwen_scale_f16`, il kernel L2 di S12 non lo include).
- Funzioni Metal: `qwen_deltanet_conv_silu` (32 thread/gruppo, 1 thread per canale),
  `qwen_deltanet_gates` (64), `qwen_scale_f16` (256).

## Note per le sezioni successive

- S15 (ricorrenza): i beta/decay FP32 `[tokens][32]` e q/k/v FP16 normati escono già nel layout
  che la scansione richiede; `qwen_deltanet.metal` ha il posto per la ricorrenza sotto i kernel S14.
- S18/S19 (runner): `encodeL2PerHead` richiede layout compatto — per le fette a stride 8192 servono
  o un parametro `rowStride` nel kernel S12, o dispatch per riga (costoso: 1 dispatch per token).
  Consigliato aggiungere il parametro in S18 con test proprio.
- Lo stato conv è riusabile in place (legge i 3 slot nei registri prima di scrivere): il runner
  può passare lo stesso buffer come `stateIn`/`stateOut`.
- La continuità prefill↔decode è bit-esatta: nessun lavoro extra richiesto al runner.
- L2 + scale vanno in command buffer separati (kernel nello stesso encoder possono sovrapporsi).
