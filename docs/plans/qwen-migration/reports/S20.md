## Valori misurati o fissati
- 2026-11-11 (passo 1): `PrefillRuntimeConfig.maxChunkTokens = 256`, `allowedChunkTokens = [32, 64, 128, 256]`, `defaultChunked = 128`. Pesi Qwen 4-bit = affine MLX gruppo 64, stesso layout servito da `MPPPrefillInt4QMM` per Gemma → GEMM con `m = T` per tutte le proiezioni 4-bit; path Apple10 veloce se `m ≥ 64` e `k % 128 == 0` (altrimenti path F16 di controllo, corretto per `m ≥ 1`). Router 8-bit: `MPPPrefillInt8QMM` richiede `weightsOffset % 4 == 0` (verifica runtime, altrimenti GEMV per token). `QwenMoE.encodePrefill` usa gli stessi 8 blob per tutti i token (`maxSlots = 8`): per T righe serve l'unione degli id del blocco + arg buffer per token (decisione nella mappa). `QwenHybridCache` (S18) ha già `snapshot()`/`restore(_:)`/`truncate(to:)` per D6 (`snapshot() ≈ 63 MiB`, `Snapshot.position` public).
