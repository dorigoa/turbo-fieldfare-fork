## Deviazioni dal piano
- La scheda elenca i passi in ordine logico; i commit mappano: passo 1 = kernel `qwen_moe_gate_up_silu`/`qwen_moe_down`/`qwen_moe_residual` + wrapper `QwenMoE` + reference + test per stadio; passo 2 = uso shared expert (slot singolo) col gate scalare S13; passo 3 = test uscita+residuo del blocco; passo 4 = ciclo di prefill; passo 5 = suite completa e guardie.
- I kernel non riutilizzano `DequantInt4GEMV`/`SharedExpertInt4` di Gemma (richiedono SiLU, non GELU, e i file Gemma non sono toccabili dalla scheda): `qwen_moe.metal` contiene una propria GEMV INT4 affine con la stessa codifica di `dequant_int4.metal`.
